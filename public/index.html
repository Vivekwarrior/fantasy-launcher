About

          

            Fantasy Launcher 1.0

            Made by dr.denji · contact: Instagram @loid_edits1


            A lightweight Minecraft launcher — real game downloads, one-click mods and performance pack, Fabric/Quilt/Forge/NeoForge loaders, offline profiles, Dark & Divine themes.


            Shaders: install the performance pack — it includes Iris (Fabric/Quilt) or Oculus (Forge/NeoForge), so shaders run on the optimized engine. Java is handled automatically.
          

          

        

      


      

        
Keybind presets

        
Set your controls in-game once, then save them here by name and apply any preset later with one click. Only the keybind lines of options.txt change — a .bak backup is created first.
